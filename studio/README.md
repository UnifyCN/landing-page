# Sanity Clean Content Studio

## Article sections and photos

- In Body, select Heading 2 or Heading 3 from the style menu. The website creates the table of contents from these headings. Empty headings do not appear.
- Use Heading 2 for a main section. Use Heading 3 for a subsection. Bold text alone does not create a section.
- Each heading keeps its link when you change its text or move its block. Deleting and adding a heading creates a new block and link. Older headings without a block key use their text, so their links change if you edit the text.
- Insert Image within Body to place a photo between paragraphs. Thumbnail supplies the article cover and blog card only.
- Add Alternative text that describes the photo. Add an optional Caption for context or a credit. Captions display as plain text.
- Use the crop tool to select the visible area. Article photos keep that crop and its ratio. A hotspot does not cause an extra crop.
- Missing photos and alternate text produce warnings. These warnings do not prevent publication of older posts. Older photos use their caption as alternate text if needed. Photos with neither field keep an empty alternate text value. Add a description when you next edit these photos.
- Publish the post to show changes on the website. The preview shows the published version. The website cache can take five minutes to update.

Congratulations, you have now installed the Sanity Content Studio, an open-source real-time content editing environment connected to the Sanity backend.
